WOINTS · OVERLAY SPEC · v0.1

Keyboard hint overlay for Hyprland

Badges on a transparent full-screen layer. Every element below is a rounded rect, an optional 1 px stroke, and one text run — directly reproducible in tiny-skia. Colours: Catppuccin Mocha (dark, default) and Latte (light).

Assumptions
• Badges are opaque, so label contrast never depends on what is underneath. Only the badge edge does — tested in 08.
• Units are logical px × output scale, rounded to device px; the badge origin snaps to the device grid.
• Latte flash/drag text borrows Mocha crust #11111b: no Latte colour reaches AA on Latte green or peach.
• Grey dashed lines in this doc are annotations, not overlay. Tweaks: theme, label case, typed-prefix treatment.

Placement rules
1 · Preferred slot: top-left + (−3, −3); targets < 20 px are centred.
2 · Clamp inside the output with a 1 px inset (see 09).
3 · Place in reading order (y, then x). If the rect + 2 px gap hits a placed badge, try: below (top = bottom + 1) → right of blocker (+gap, max 3 hops) → above (bottom = top − 1).
4 · Still colliding: keep it; draw over, one z-step higher. Rare — log it.
5 · Skip targets < 50 % visible or fully occluded by another window.
6 · Short labels go to the largest, most central targets first.

Each output gets its own layer surface rendered at its own scale (wp_fractional_scale_v1 + viewporter). Never render once at max scale and downsample.
Logical sizing assumes the compositor scale matches density. Here it doesn't quite: 11 px = 3.04 mm on DP-1 vs 2.30 mm on eDP-1.
hint.size_unit = "mm" + hint.size_mm = 3.0 uses wl_output physical size: DP-1 → 11 device px, eDP-1 → 29 device px (14.5 logical). Padding and radius scale by the same factor. Falls back to logical if the output reports 0 mm.
Hints never span outputs; a window crossing the seam is hinted on the output holding its target centre.
